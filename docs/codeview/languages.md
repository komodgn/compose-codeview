## 🦧 Language Support

### Supported Languages

Currently, CodeView offers out-of-the-box support for the following languages:

- Kotlin
- Java
- Python

### Highlighted Elements

CodeView identifies and styles key components of each language to ensure maximum readability:

- **Keywords**: Reserved words such as `fun`, `class`, `def`, and `val`.
- **Types & Functions**: Automatically detects class names (UpperCamelCase) and function calls to provide rich visual context.
- **Strings & Literals**: Distinct styling for text data and numeric values.
- **Comments**: Proper rendering for both single-line (`//`, `#`) and multi-line (`/* */`) comments.

## 🙋 Contributing New Languages

CodeView is designed to be extensible! If the language you need is not currently supported, we welcome your contributions!

You can contribute by:
* **Opening a Pull Request**: Implement a new `LanguageDefinition` and submit your PR.
